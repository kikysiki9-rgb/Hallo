# Калькулятор

Простой адаптивный веб-калькулятор на HTML, CSS и JavaScript. Работает прямо в браузере — установка и дополнительные зависимости не требуются.

## Возможности

- Базовые арифметические операции: сложение, вычитание, умножение и деление.
- Поддержка десятичных чисел.
- Кнопки очистки (`C`) и удаления последнего символа (`DEL`).
- Отображение результата и сообщение об ошибке при делении на ноль.
- Интерфейс с сеткой кнопок, градиентным фоном и адаптивной шириной.

## Запуск

Откройте `calculator.html` в любом современном браузере. Для локального запуска не нужны Node.js, сборка или сервер.

## Использование

1. Нажимайте цифры и операторы, чтобы составить выражение.
2. Нажмите `=` для получения результата.
3. Нажмите `C`, чтобы сбросить вычисление, или `DEL`, чтобы удалить последний символ.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript

Вся разметка, стили и логика находятся в одном файле — `calculator.html`.
